# Rollenpreis 🧻

Klo- und Küchenrollen nach Blattpreis vergleichen. Fürs Handy, mit Offline-PWA und lokal gespeicherten Angeboten.

```sh
curl -fsSL https://raw.githubusercontent.com/forke24x7/rollenpreis/main/docker-compose.yml -o docker-compose.yml
docker compose up -d --build
```

Öffnen: `http://SERVER-IP:8841` · anderer Port: `ROLLENPREIS_PORT=8842` in `.env`.

Für die PWA einmal über HTTPS öffnen und zum Home-Bildschirm hinzufügen.
